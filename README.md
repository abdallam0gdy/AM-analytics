# AM Analytics - منصة رصد وتحليل المنافسين التعليميين 📊🧠

**AM Analytics** هي لوحة تحكم ذكية مبنية باستخدام **React** و **Vite** متكاملة مع **Supabase** و **Gemini AI API** لمساعدة أصحاب المنصات التعليمية والمحاضرين في رصد وتحليل قنوات يوتيوب للمنافسين في مادة "البرمجة والذكاء الاصطناعي" للمرحلة الثانوية المصرية (أولى وتانية ثانوي). 

توفر المنصة أدوات سحب وتحليل حية للتعليقات، وتحديد فجوات المحتوى، واستخلاص نقاط القوة والضعف لتطوير وتقديم تجربة تعليمية متفوقة.

---

## 🌟 أبرز المميزات (Key Features)

### 1. رادار يوتيوب النشط (YouTube Active Radar)
* رصد وسحب تلقائي للفيديوهات التعليمية المرفوعة حديثاً بناءً على كلمات بحث مخصصة.
* مطابقة وتحقق فوري من صلة الفيديوهات بالمنهج التعليمي المصري والمواضيع الوزارية عن طريق الذكاء الاصطناعي.

### 2. التحليل النشط والفوري للمنافسين (On-Demand Scraper & AI Analyzer)
* زر تحليل مباشر داخل كرت كل مدرس يقوم بـ:
  * جلب أشهر محاضراته وأحدثها من يوتيوب.
  * **فلترة ذكية للإعلانات:** استبعاد الفيديوهات الترويجية والقصيرة (أقل من دقيقتين) والتركيز على الفيديوهات التعليمية.
  * سحب آخر تعليقات الطلاب ومعالجتها بالـ AI.
  * تحديث فوري لنقاط قوة المدرس وضعفه وحفظ النتائج في قاعدة البيانات.

### 3. تحليل تعليقات الطلاب العميقة (Deep Student Comments Insights)
* قراءة تعليقات الطلاب واستخراج نقاط الألم (ما لم يفهموه)، والمفاهيم الناقصة في الشرح، وطلبات الطلاب المحددة (مثل طلب ملخصات أو ملازم).
* تقييم المشاعر العامة للطلاب (إيجابية، سلبية، مختلطة) وتحديد درجة التفاعل الكلية للمحاضرة.

### 4. لوحة تحكم وإحصائيات ذكية (Premium Dashboard & Visualizations)
* كروت Bento متطورة لعرض إجمالي المشاهدات، المشتركين، متوسط المتابعين، وتوصيات المحتوى الذكية.
* رسوم بيانية تفاعلية باستخدام **Recharts** لمقارنة حجم القنوات ونسب المتابعين.
* شريط بحث متقدم وفلاتر لتصنيف المنافسين حسب الصفوف الدراسية (الصف الأول الثانوي / الصف الثاني الثانوي).

### 5. دعم كامل للوضع الفاتح والداكن (Adaptive Light/Dark Mode)
* واجهة مستخدم متميزة تتكيف تلقائياً مع نظام التشغيل مع إمكانية التبديل اليدوي السلس، وتحديث الألوان والشعارات بشكل ذكي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** React.js, Vite, Tailwind CSS v4, Lucide Icons, Recharts.
* **Backend & Database:** Supabase (PostgreSQL) لربط الفيديوهات والمنافسين والتعليقات والتحليلات.
* **AI Engine:** Google Gemini Developer API (باستخدام الموديلات النشطة مثل `gemini-3.5-flash` و `gemini-3-flash` و `gemini-3.1-flash-lite` مع دعم كامل للفيل أوفر الفوري عند نفاد الكوتا اليومية).

## 🚀 طريقة التشغيل والتهيئة المحلية (Installation & Setup)

### 1. استنساخ المشروع (Clone Repository)
```bash
git clone https://github.com/your-username/am-analytics.git
cd am-analytics
```

### 2. تثبيت الحزم البرمجية (Install Dependencies)
```bash
npm install
```

### 3. إعداد البيئة (Environment Variables)
قم بإنشاء ملف `.env` في المجلد الرئيسي للمشروع وأضف المتغيرات التالية:
```env
VITE_SUPABASE_URL=https://your-supabase-project.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anonymous_key
VITE_YOUTUBE_API_KEY=your_youtube_data_api_v3_key
VITE_GEMINI_API_KEY=your_google_gemini_api_key
```

### 4. تشغيل خادم التطوير (Run Development Server)
```bash
npm run dev
```

### 5. بناء نسخة الإنتاج (Build for Production)
```bash
npm run build
```

## 📁 الهيكل البرمجي للمشروع (Project Structure)

```text
├── src/
│   ├── components/       # المكونات المشتركة وتخطيط الصفحة (Header, Sidebar...)
│   ├── data/             # البيانات المحلية الاحتياطية (Mock Data)
│   ├── hooks/            # الخطافات المخصصة للاتصال بـ Supabase (useSupabaseData)
│   ├── lib/              # الخدمات الأساسية (Supabase client, Gemini API, Scraper Pipeline)
│   ├── pages/            # صفحات الموقع (Overview, Competitors, AIReports)

│   └── main.jsx          # نقطة دخول التطبيق
├── supabase/
│   └── schema.sql        # هيكل الجداول والـ Schema لقاعدة البيانات لقراءة وتهيئة Supabase
├── .env                  # متغيرات البيئة السرية (API Keys)
└── README.md             # ملف التعريف البرمجي للمشروع
```
